# Hospital Appointment No-Show Analysis Dashboard

## 📌 Project Overview
This Power BI dashboard analyzes hospital appointment no-show patterns using different factors such as travel distance, appointment day, reminders, employment status, chronic condition, and time slots.

The dashboard helps hospitals understand patient behavior and reduce appointment no-shows.

---

## 🎯 Objectives
- Analyze no-show appointment trends
- Identify factors affecting patient attendance
- Study travel distance and travel time impact
- Analyze reminder effectiveness
- Understand no-show behavior by gender and city type

---

## 📊 Dashboard Features
- Total Appointments
- Total No-Shows
- No-Show Rate
- Average Travel Distance
- No-Show Rate by Distance Group
- No-Show Rate by Travel Time
- No-Show Rate by Appointment Day
- No-Show Rate by Time Slot
- No-Show Rate by Employment Status
- No-Show Rate by Chronic Status
- SMS Reminder Analysis
- Number of Reminder Analysis

---

## 🛠️ Tools & Technologies Used
- Power BI
- Excel Dataset
- DAX Functions
- Data Visualization
- Data Cleaning & Transformation

---

## 📈 Key Insights
- Evening appointments showed higher no-show rates.
- Patients traveling longer distances had increased no-show rates.
- SMS reminders reduced appointment no-shows.
- Urban patients contributed more appointments.
- Holiday and normal day no-show rates were nearly similar.
